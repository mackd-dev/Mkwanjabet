# Typography

**Primary typeface:** Montserrat

| Weight   | Name           | Use                          |
| -------- | -------------- | ---------------------------- |
| Bold     | Montserrat Bold | logo wordmark, monogram     |
| SemiBold | Montserrat SemiBold | taglines, buttons        |
| Regular  | Montserrat Regular | body text, captions       |

## Hierarchy
- H1 / Hero: Bold, ~48–80px
- H2 / Section: Bold, ~32–48px
- H3 / Card: SemiBold, ~20–28px
- Body: Regular, 16–18px
- Caption / Meta: Regular, 12–14px, color `#808080`
