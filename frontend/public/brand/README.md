## Color Tokens (verified against source kit)

| Token        | Hex       | Use                                       |
| ------------ | --------- | ----------------------------------------- |
| Yellow       | `#FFD700` | primary accent / M letter / CTAs          |
| Dark Green   | `#006B2F` | wordmark "BET", supportive surfaces       |
| Bright Green | `#00B341` | secondary accent, swoosh, success states  |
| Black        | `#111111` | primary background, body surfaces         |
| White        | `#FFFFFF` | main wordmark "MKWANJA", inverse fills    |
| Grey         | `#808080` | meta text / disabled                      |

## Typography

- **Primary typeface:** Montserrat
- **Weights shipped:** Bold (900) / SemiBold (600) / Regular (400)
- **Use:** M+B monogram and wordmark always Bold; tagline SemiBold;
  body text Regular. Substitute DejaVu Sans / Liberation Sans Bold / Arial
  when Montserrat is unavailable; SVG falls back to those stacks.

## Brand Voice

- Confident, sports-driven, high-contrast.
- "Play Smart. Win Big." — short, imperative, dual green/yellow accents.
